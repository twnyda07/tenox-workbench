# 十牛圖修行指南　編輯協作台

內部編輯用。內容為 AES-GCM 加密（PBKDF2-SHA256 200k），沒有密碼連這個 repo 裡都看不到明文。

後端（裁示同步）需要 token 才能讀寫，token 由協作台密碼派生，不存在於任何檔案中。
首次上線或改過密碼，請依 `設定指南.md` 操作。

- 十冊撰稿本：388 節，每節掛好素材
- 公案總帳：兩線合一後的 295 則，含完整敘述權與跨階遞進
- 人物事例：662 則的判定
- 待裁示：212 項，決定即時同步給所有人

請勿外傳網址與密碼。

---

- `設定指南.md` —— 後端上線設定，四步，含驗收
- `token.html` —— 從密碼算出後端 token（純前端運算，不連網）
- `apps-script/Code.gs` —— 後端存取控制，貼進 Apps Script
- `分析報告.html` —— A 線：攤平 388 節骨架，產對照表、素材缺口、公案總帳與人物事例（純前端，可匯出 CSV／Markdown）
